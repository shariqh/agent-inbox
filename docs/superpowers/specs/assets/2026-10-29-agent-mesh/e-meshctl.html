meshctl

1Dry run by default, like install-agents.sh; --apply writes atomically with a backup and touches nothing it does not own.
2status reads mesh.json and, if the console is on, one registry request. It never starts a process.
3The same numbers as the Mesh value panel (§17), from GET /v1/mesh/metrics.
4send is the hand-driven path used by M2 and M4: same chain, same click, same grant as an agent's delegate.
5The optional acceptance answer is the human verdict that the acceptance and rework metrics count. Enter skips it.
6The scenario bench (§17.2) ships in packages/mesh, not the app. It runs each task delegated and in-session and writes a summary for the phase checkpoint.
7Any mesh identity can pause; only the console key on the hub can resume.
8disable leaves no blocked @mesh row behind (§2.5).
